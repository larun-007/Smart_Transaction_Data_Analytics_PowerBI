# Power BI assets

This folder contains DAX measures and a Power Query M starter for the report. The native `.pbix` must be created and saved in Power BI Desktop after importing the dataset.

- `DAX_Measures.dax`: create each measure separately using **Modeling → New measure**. Paste one measure definition at a time, including its measure name and `=`.
- `Power_Query_Cleaning.pq`: optional starter query. Replace `C:\YOUR_FOLDER\...` with your real path before using it in Advanced Editor. The UI instructions in `docs/POWER_BI_BUILD_STEPS.md` are a simpler alternative.
